# Mu2e complete experiment

Render five bright, edge-faded views of the complete Mu2e v7.4.1 geometry
used by the official 2019 Geometry Browser tutorial:

```sh
./examples/mu2e/render.sh
```

Pass one or more view names to render only those figures:

```sh
./examples/mu2e/render.sh solenoid-train
./examples/mu2e/render.sh facility-cutaway detector-cutaway
./examples/mu2e/render.sh detector-core detector-axial
```

With no argument, the script renders all five. It needs `curl`, `tar`, and
`rsvg-convert`. It streams one content-addressed layer from
`mu2e/user:tutorial_1-03`, stops after extracting
`Tutorials_2019/GeometryBrowsing/mu2e_v7_4_1.gdml`, and verifies the GDML's
SHA-256 checksum before parsing it. The Docker image is not pulled, the layer
archive is never written to disk, and no Mu2e repository is cloned. Only the
exact 5.0 MB GDML member is retained under `out/mu2e/source/`.

Inventories, reader diagnostics, and generated SVG, PDF, and PNG views are
written beneath the ignored `out/mu2e/` directory. Set `G4FIG_BIN` to use a
particular local renderer binary; otherwise the script calls `bin/g4fig`.

## Verified scale

`g4fig --list` expands the pinned export to 175,539 placed-volume rows, 3,984
distinct logical-volume names, 57 materials, and 13,351,500 placed facets,
with a maximum depth of nine. The source itself contains 4,262 volume
definitions and 14,434 explicit physical-volume elements.

The export covers the production, transport, and detector solenoids;
production and stopping targets; tracker; calorimeter; cosmic-ray veto;
shielding; building; and surrounding earth. The five views separate the
facility, solenoid train, and detector systems so the apparatus remains
legible at each scale.

## Provenance

[`SOURCES.tsv`](SOURCES.tsv) records the exact image tag, immutable layer
digest, archive member, checksum, and official tutorial page. The tutorial
geometry was generated by Mu2e Offline; its source repository is Apache-2.0,
while the exported GDML carries no separate embedded licence notice. See the
[stacked Mu2e gallery](../../gallery/mu2e-views.md) for all five views.
